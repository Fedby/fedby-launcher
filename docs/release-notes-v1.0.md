Fedby 启动器 **v1.0** 是第一个正式版本。目标很朴素：少折腾，点两下就能进游戏。

---

## 先看这里：下哪个

| 文件 | 说明 |
|---|---|
| `FedbyLauncher-Portable-1.0.0.exe` | **便携版，推荐**。单文件、免安装，双击即运行，可以放 U 盘带走 |
| `FedbyLauncher-Setup-1.0.0.exe` | 安装版。可选安装目录，自动创建桌面与开始菜单快捷方式 |

**系统要求**：Windows 10 / 11（64 位）。启动器本体约 300 MB。

**首次使用三步**

1. 打开启动器，点「＋」加一个离线账户，或点微软徽标登录正版
2. 到「版本」页点「安装版本」，选一个正式版下载（例如最新的 26.x）
3. 回「启动」页点「启动游戏」，Java 和内存会自动配好

> 启动器本体**不自带游戏文件**，游戏本体需要自己下载一次（26.3 约 800 MB）。之后版本存在本地，升级启动器不用重下。

## 这个版本有什么

**启动**

- 账户条直接长在主页上，点头像就能换账户，不用来回翻页
- 版本、Java、内存一屏看完，启动按钮常驻底部
- 实时日志滚动输出，崩了能直接看到原因
- 自动选择 Java（按版本要求取「够用的最低版本」）、自动分配内存（物理内存 1/4，限制 2~8 GB），随时可以关掉改手动

**版本管理**

- 从 Mojang 官方源安装正式版与快照，含依赖库和资源文件，逐个 SHA1 校验，多线程下载
- 「检查」弹窗分五个标签：基本信息、模组、资源包、光影、存档，每个标签都能一键打开对应文件夹
- 基本信息页提供版本目录、游戏根目录、模组、资源包、光影、存档、备份七个快捷入口

**下载中心**

- Modrinth + CurseForge 双源搜索，模组、整合包、资源包、光影、地图、插件、数据包七类资源
- 首页热门模组推荐，点开直接挑版本装
- 模组名显示中文：人工校对词库 → MC百科 → 麦块社区，都没有就保留英文，不做机翻
- 安装前按「游戏版本 + 加载器 + 关键词」三重筛选，默认已匹配当前版本；依赖自动装，重复文件自动跳过

**账户**

- 离线账户：UUID 由用户名稳定生成，存档不会串号
- 微软正版：内置微软官方登录窗口，登录后自动同步皮肤头像，令牌临近过期静默续期
- 第三方皮肤站：标准 Yggdrasil 协议，支持 LittleSkin / Blessing Skin；配上 `authlib-injector.jar` 后游戏内皮肤也生效

**设置**

- 8 种主题色 + 自定义取色，改完立刻生效
- Java 运行时扫描与手动指定、内存与分辨率、全屏、额外 JVM 与游戏参数
- 下载并发数、社区中文数据开关、CurseForge API Key、数据目录直达

---

## 已知限制

- **没有代码签名**，Windows 首次运行会提示「未知发布者」，点「更多信息 → 仍要运行」即可
- 只提供 **Windows x64** 版本
- 启动器不自带游戏文件，需要联网下载一次
- 离线账户访问不了 Realms（预期行为，单机与局域网联机不受影响）
- 少数 CurseForge 模组禁止第三方直链下载，会提示到项目主页手动下载
