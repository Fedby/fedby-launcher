Fedby 启动器 **v1.2** 把「下东西」这件事补全了：以前只能装原版，现在原版、加载器、模组、整合包、光影、资源包、世界、数据包全在下载中心里，选好类型点一下就装完。

| 文件 | 说明 |
|---|---|
| `FedbyLauncher-Portable-1.2.0.exe` | **便携版，推荐**。单文件、免安装，双击即运行，可以放 U 盘带走 |

## 下载中心彻底重做

左侧一列子页，每种资源各占一格，互不打扰：

**游戏** · **整合包** · **模组** · **光影** · **资源包** · **世界** · **数据包** · **插件**

- 游戏页列出 Mojang 全部 **926 个版本**，含预览版、远古版、愚人节版。找一个远古版本不用再翻网页
- 每种子页顶部都有类型标签（比如模组页的「科技 / 魔法 / 冒险 / 优化 / 装饰」），**点标签直接重新搜索**，不用再点确定
- 每页默认给一排推荐，挑不出要什么就从热门里点
- 换了 MC 版本或类型，结果立刻跟着变；切子页之后各自的筛选条件都还在

## 装版本时能顺手带加载器

以前装 Fabric 得自己去官网下 installer，现在在版本页装游戏时勾一下就行：

| 加载器 | 怎么装 |
|---|---|
| **Fabric** / **Quilt** | 读官方 profile，直接拼出启动所需的库；可选顺带装上 **Fabric API** |
| **Forge** / **NeoForge** | 调官方 installer 无头安装（`--installClient`），日志实时显示 |
| **OptiFine** | 以模组形式放进 `mods`；1.13 以后需要先选 Forge |

加载器版本可以自己挑，也可以留「推荐」，默认就选最新的稳定构建。装完直接出现在版本列表里，能启动。

## 下载源自动择优

国内直连 Mojang 有时很慢，这一版加了双源：

- **自动**（默认）：启动时给官方和 BMCLAPI 各发一个小文件测速，谁快用谁，结果缓存 6 小时
- **官方** / **镜像**：想固定就手动指定
- 某个源连续失败 4 次会自动降级 2 分钟，不会一直卡在坏节点上
- 客户端 jar、依赖库、资源文件、版本 JSON 全部走同一套择优逻辑；设置页能看到两边实测延迟

## 启动更快

首屏不再等 Java 扫描和皮肤下载：先渲染界面，这些放后台做，结果回来再补。

- 打包版从进程启动到首屏内容 **412 ms**（原来 618 ms）
- Fabric 元数据从 **113 秒降到 492 ms**——官方与镜像同时发请求，谁先回用谁
- Java 扫描结果写磁盘缓存（12 小时），二次启动不用重扫

## 顺便修的

- **下拉框全部重画**：白底圆角、展开箭头、选中打勾。版本下拉有 900 多项，超过 10 项自动带搜索框，输 `1.21` 直接过滤
- **加载器卡片重排**：外框一条完整圆角，标签和下拉同一行，整块从 120 px 收到 97 px
- 加载器版本下拉宽度固定，换版本号不再左右抽动

## 还加了自动更新

- 启动后约 2.5 秒静默查一次 GitHub Releases，**有新版本才弹窗**，没有就安静跳过
- 弹窗列出这一版更新了什么，可以「下载并安装」「稍后提醒」「跳过此版本」
- 下载完成后自动拉起安装程序，启动器随后退出
- 设置 → 关于 里可以手动检查，也能关掉启动时的自动检查

## 升级说明

- 便携版直接替换旧的 exe；安装版覆盖安装即可
- 数据目录不变（`%APPDATA%\FedbyLauncher`），账户、已装版本、存档都在
- 上一版装好的 Java 运行时继续可用，不会重复下载
- 从 1.1.0 起，启动器会自己发现这个版本并提示更新
