## 这一版加了什么

以前启动 26.x 时，如果机器上只有 Java 21，游戏会直接崩在启动阶段，还得自己去 Oracle/Adoptium 官网下 JDK、装完再回来指定路径。v1.1 把这件事交给启动器了。

**缺 Java 就自己下**

启动器会读版本的 `javaVersion.majorVersion`，判断这台机器到底缺哪个主版本（26.x → Java 25，1.21 → Java 21，1.17 → Java 17）。缺了就直接下：

- 来源是 Adoptium 的 **Temurin JRE**，SHA256 逐个校验后才解压
- 下载优先走**清华镜像**（国内实测 58.6 MB 六秒下完），镜像没有就回落 GitHub 官方 release
- 装在自己的数据目录 `%APPDATA%\FedbyLauncher\runtimes\temurin-25`，**不写注册表，不动 `JAVA_HOME`，不污染系统环境**；不想要了在设置页点删除即可
- 同一个版本并发触发只会真正下一次，重复安装直接复用已有目录

**三个触发点**

1. 启动游戏时发现缺 → 现场下载，进度条就显示在「Java 运行时」下面
2. 安装版本成功后 → 后台顺手把对应的 Java 备好，不占用安装流程
3. 设置页「下载 Java 25」按钮 → 想提前准备就点它

设置页还会给启动器自己下的运行时打上「启动器下载」标记，并提供删除按钮；启动页在缺运行时时会直接写明「缺少 Java 25，启动时自动下载」。

**顺带修的两件事**

- 启动器改为单实例：以前开两个窗口会抢同一份数据目录，在装版本或下 Java 时可能互相踩到
- 扫描 Java 时会跳过临时解压目录，`javaw.exe` 的版本探测改用同目录的 `java.exe`（GUI 子系统的程序读不到 `-version` 输出）

## 下载

| 文件 | 适合谁 | 说明 |
|---|---|---|
| `FedbyLauncher-Portable-1.1.0.exe` | 想直接用 | 单文件免安装，双击即运行，可放 U 盘带走 |
| `FedbyLauncher-Setup-1.1.0.exe` | 想长期用 | 安装版，可自选目录，自动创建桌面与开始菜单快捷方式 |

**首启用三步**：加账户（离线或微软登录）→ 版本页装一个正式版 → 回启动页点启动。缺 Java 的话这一步会自动补上，不用你管。

## 升级说明

- 便携版直接替换旧的 exe 即可；安装版覆盖安装
- 数据目录不变（`%APPDATA%\FedbyLauncher`），版本、账户、存档都在
- 已经装好 Java 25 的机器不会触发下载，行为和 1.0 一致

## 实测记录

- 下载链路：Adoptium API 返回 Temurin 25.0.5，58.6 MB 包走清华镜像 6 秒下完，SHA256 与官方公布值一致；解压 382 个文件 / 179 MB，`java -version` 为 `25.0.5.1`
- 界面链路：进度条在下载/解压阶段连续 12～27 次采样可见，完成后徽章变「启动器下载」，重复调用不再下载
- 真实启动：用下载来的 Temurin 启动 26.3，68 行日志、进入主菜单、零控制台错误
- 回归：服务层 17 项全通过；四个页面渲染零错误；离线账户端到端启动正常

## 已知限制

- 只支持 Windows 10 / 11 64 位（与启动器主体一致），下载的是 x64 的 JRE；ARM64 机器会按 `aarch64` 尝试取包
- 没有代码签名证书，首次运行仍会提示「未知发布者」
- 下载源依赖 Adoptium 与清华镜像的可用性；两个都不可用时会给出手动指定的提示
